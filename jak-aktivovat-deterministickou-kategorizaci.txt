Jak aktivovat automatické (deterministické) doplnění taxonomie
=============================================================

Branch: taxonomie-v2-a-deterministicka-kategorizace
Stav: zatím NENÍ slitý do main.

"Aktivace" má dvě roviny podle toho, co s branchem chceš:


1. Jen si ho vyzkoušet (bez zásahu do main)
-------------------------------------------

    git checkout taxonomie-v2-a-deterministicka-kategorizace
    python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

Modul kategorizace/ je samostatný, na dodavatele.py napojený NENÍ – má
vlastní CLI a vlastní výstupní soubor. Potřebuje klíč k serper.dev
(Google Search API, https://serper.dev):

    export SERPER_API_KEY=...
    # nebo: klíč vlož do souboru kategorizace/serper_key.txt

Spuštění:

    .venv/bin/python -m kategorizace.kategorizuj vstup.csv -o vystup_kat.csv
    # jen z keše, nic nestahovat:
    .venv/bin/python -m kategorizace.kategorizuj vstup.csv -o out.csv --offline

Ve výstupu je sloupec Rozhodnutí:
    AUTO   (~37 %) – kategorie převzata rovnou, ~96% přesnost listu
    OVERIT (~33 %) – návrh s nižší jistotou, doporučená kontrola
    LLM    (zbytek) – nezařazeno, necháváš na původní LLM krok

Žádné další závislosti nejsou potřeba, openpyxl jen na čtení/zápis XLSX.


2. Natrvalo do main
-------------------

    git checkout main
    git merge origin/taxonomie-v2-a-deterministicka-kategorizace

Pozor: tenhle merge zároveň přepíše taxonomie_data.json na verzi v2
(74 kategorií / 11 skupin + příznak ICT relevance), což ovlivní i
dodavatele.py a build GUI. To je záměr toho branche, ale je dobré
o tom vědět.
